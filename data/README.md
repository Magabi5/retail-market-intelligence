# Dados

A base original utilizada no desafio não é disponibilizada neste repositório.

O projeto foi construído a partir de um conjunto de dados fictício fornecido exclusivamente para realização do case. Para preservar o material original recebido, este portfólio apresenta apenas:

- metodologia utilizada;
- medidas DAX;
- resultados agregados;
- visuais do dashboard;
- documentação e recomendações.

Os números exibidos no projeto são resultados agregados da análise e servem apenas para demonstrar o processo analítico.
